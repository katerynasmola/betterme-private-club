# Зміни: пошук і відображення імені (2026-08-12)

Підсумок правок навколо поля "Full name" у чек-іні (`apps-script/Code.gs`, `apps-script/Index.html`, `apps-script/JavaScript.html`).

## 1. Виправлено колонки після додавання імені/пошти

Колонки B і C (англійське ім'я, пошта) додались у вкладку `Private Club Kyiv | Registration (landing)` для проєкту Reformer Session, і змістили статуси чек-іну:

- Пошук/збіг імені — тепер по колонці **B** (англійське ім'я), а не A.
- Kyiv статус/час → колонки **D/E** (було B/C).
- Warsaw статус/час → колонки **F/G** (було D/E).

## 2. Прибрано підказку Chrome з платіжними картками

Chrome пропонував збережені картки при фокусі на полі імені через слово "name" в `id`. Поле перейменовано з `id="name-input"` на `id="participant-field"` в Index.html і JavaScript.html.

## 3. Двомовний пошук і відображення (укр / англ)

- `getNames()` тепер повертає пари `{uk, en}` замість одного рядка (колонки A і B).
- Пошук шукає збіг і в українському, і в англійському варіанті — незалежно, якою мовою вводить людина.
- У випадному списку кожен варіант показується як `Прізвище Ім'я / Name Surname`.
- Для запису чек-іну в таблицю (`checkIn`) і далі використовується англійське ім'я — колонки D–G не зачепило.

## 4. Пошук за словами незалежно від порядку

Українська колонка зберігає імена як "Прізвище Ім'я" (наприклад "Смола Катерина"), тож запит "Катерина Смола" не знаходився як точний підрядок. Тепер запит розбивається на слова, і кожне слово шукається окремо в імені — порядок слів більше не важливий.

## Що потрібно задеплоїти

Файли **Code.gs** і **JavaScript.html** з папки `apps-script/` — вставити в Apps Script цього проєкту, зберегти, і зробити **Deploy → Manage deployments → Edit → New version → Deploy**.
